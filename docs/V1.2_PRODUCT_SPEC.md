# V1.2 产品与验收规格

## 目标

面向 Windows 个人开发者和知识工作者，提供可安装的原生 AI Agent：能保存会话、按项目限制文件范围、流式回答、在确认后修改文本文件，并可在应用运行时执行只读周期任务。

## 核心流程

1. 用户在设置中配置兼容端点、模型和 API Key。
2. 用户创建项目并选择真实本地目录。
3. 用户新建任务，选择项目和权限模式后输入目标。
4. 模型流式返回；需要文件时发起工具调用。
5. 读取自动进行；写入弹出工具名和参数，用户可单次允许或拒绝。
6. 对话和结果自动保存，重启后可继续查看。

## 视觉规格

- 深色主背景 `#141414`，面板 `#1F1F1F`，卡片 `#242424`，边框 `#343434`。
- 主文字 `#F3F3F3`，次文字 `#A8A8A8`，强调绿 `#00BB6B`。
- 左侧展开宽 264、折叠宽 72；默认窗口 1280×800，最小 1024×720。
- 卡片圆角 12–14，输入和按钮圆角 8，基本间距单位 4。
- 正文默认系统字体，中文由 Microsoft YaHei UI/系统回退；正文 14，页面标题 24–26。

## 交互规格

- Ctrl+Enter 发送，运行期间显示“停止”；发送、项目和权限选择在运行中禁用。
- 流式内容追加到当前助手气泡，工具状态显示在页头。
- 默认权限下写文件必须显示确认弹窗；关闭或拒绝都不得执行写入。
- 项目删除只删配置，必须明确说明不会删除本地文件。
- 删除 API Key 和自动化均需二次确认。
- 空状态必须说明可做什么，不显示假数据。

## 错误与恢复

- 网络和模型错误显示 HTTP 状态与截断后的响应，不显示密钥。
- 路径越界、链接、文件过大、哈希冲突以明确中文错误返回。
- 用户停止贯穿模型流；已完成的文件操作不自动回滚。
- 数据库使用 5 秒 busy timeout；写入会话与更新时间在同一事务。
- Agent 达到步骤/工具上限或无进展时明确停止，不无限重试。

## 发布验收

- [ ] Windows 10 1809 和 Windows 11 x64 各完成一次安装、启动、卸载。
- [ ] 未安装系统级 Windows App SDK Runtime 的干净虚拟机可启动自包含发布。
- [ ] 安装后创建项目、保存 API Key、发送流式任务成功。
- [ ] `../`、绝对路径、符号链接、目录联接全部被拒绝。
- [ ] 512 KiB 以上读取、1 MiB 以上写入被拒绝。
- [ ] 外部修改后使用旧 `expected_sha256` 写入返回冲突。
- [ ] 默认、只读、完全访问三种权限矩阵符合安全文档。
- [ ] 停止按钮能终止慢速模型流，应用仍可继续新任务。
- [ ] 自动化到期只运行一次，应用退出期间不补跑。
- [ ] API Key 未出现在数据库、日志、崩溃信息和安装目录。
- [ ] 安装器与二进制完成 Authenticode 签名后再公开分发。
