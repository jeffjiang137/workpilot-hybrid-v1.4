## 必须在 Windows 执行

当前 Linux 环境通过临时 .NET 8 SDK 完成了托管编译与测试，但没有 MSVC、可执行的 WinUI XAML Compiler、DPAPI/Job Object 运行环境和 Inno Setup，因此不能在此声称 Windows 二进制已实际构建。WinUI 交叉构建已确认会停在 Windows 专用 `XamlCompiler.exe`（Linux `Exec format error`），不是产品源码测试的通过结果。接收源码包后在 Windows x64 双击 `build-installer.bat`，只有脚本全部通过才产生安装包。需要重点验证：

1. Release x64 C++/C# 编译和 Native ABI。
2. WinUI XAML 编译与四个新增页面的键盘/缩放。
3. DPAPI 凭据、OAuth loopback、Job Object 进程回收。
4. GitHub/Notion 测试账号和本地/远程 MCP 契约。
5. V1.3 实际用户数据库覆盖升级与 Inno 安装/卸载。

任何 Windows 门禁失败都不应分发安装器；应保留完整错误输出后修复源码重新打包。
