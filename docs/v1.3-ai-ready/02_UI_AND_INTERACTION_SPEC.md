# V1.3 UI 与交互规格

## 1. 设计基线

继续使用 V1.2 WinUI 3 深色设计，不引入 WebView 或第二套组件库。

| Token | 值 | 用途 |
|---|---|---|
| `Background.Primary` | `#141414` | 窗口与页面背景 |
| `Background.Secondary` | `#1F1F1F` | 侧栏、详情面板 |
| `Background.Card` | `#242424` | 卡片、输入容器 |
| `Background.Hover` | `#2D2D2D` | 悬停 |
| `Border.Default` | `#343434` | 常规边框 |
| `Text.Primary` | `#F3F3F3` | 主文字 |
| `Text.Secondary` | `#A8A8A8` | 次文字 |
| `Accent.Primary` | `#00BB6B` | 主操作和成功 |
| `Warning` | `#F2B84B` | 到期、暂停、限制 |
| `Danger` | `#FF5A5F` | 仅确认层的危险操作 |
| `Focus` | 系统 Accent | 键盘焦点环 |

页面标题 24/32 SemiBold；区块标题 18/26；正文 14/20；辅助文字 12/18。所有点击目标至少 32×32；输入框至少 40 高；卡片圆角 12；侧栏展开 264、折叠 72；窗口最小 1024×720，推荐 1280×800。

## 2. 全局导航调整

### 2.1 导航结构

按以下顺序显示，不允许增加未实现入口：

1. 顶部空间切换器。
2. 新任务。
3. 任务。
4. 项目。
5. 资产。
6. 自动化。
7. 底部设置。

“新任务”继续进入 AI 对话；“任务”进入正式任务页。二者图标和文案不得相同。

### 2.2 空间切换器

- 展开侧栏：宽度填满，左侧 10×10 颜色圆点，中间空间名，右侧 ChevronDown。
- 折叠侧栏：仅显示颜色圆点外包的 32×32 按钮，Tooltip 显示空间名。
- 点击弹出 `MenuFlyout`，最大高度 420；顶部搜索仅当空间数大于 8 时出现。
- 列表分“当前”“其他”“已归档”；默认不展开已归档。
- 底部固定“管理空间”和“新建空间”。
- 切换后按钮先显示进度环，最多 2 秒；加载失败恢复原选择并显示 InfoBar。

### 2.3 全局状态

- 后台索引运行时，资产导航项右侧显示小型 ProgressRing；折叠时使用 Tooltip。
- 达到索引限制或发生错误时显示黄色/红色状态点，不使用系统通知打断用户。
- 页面切换不销毁正在编辑但已保存的数据；存在未保存表单时必须执行离开确认。

## 3. 空间管理

空间管理使用居中的 `ContentDialog`，推荐宽 720、高度不超过窗口 80%。空间数较多时内部滚动。

### 3.1 列表

每行高 56，显示颜色、名称、项目数、未完成任务数、归档状态和更多菜单。行点击进入编辑；更多菜单只有“归档/恢复”和满足条件时的“删除”。

### 3.2 新建/编辑表单

- 名称 TextBox，实时显示 `当前文本元素数/40`，只在失焦或保存时显示错误。
- 描述 TextBox，接受换行，最大 4 行可见。
- 颜色为 8 个 32×32 单选色块，必须有 `AutomationProperties.Name`。
- 底部按钮：取消、保存；保存过程中禁用表单并显示 ProgressRing。
- Esc 等同取消；有未保存内容时二次确认。

### 3.3 删除确认

标题“删除空间？”；正文明确“不会删除本地文件”。若不可删除，确认按钮不出现，显示剩余项目和任务数量及对应页面入口。

## 4. 任务页面

### 4.1 页面结构

页头 64 高：左侧“任务”和当前空间名；右侧视图切换、筛选、新建任务。

第二行工具栏：

- 搜索框，宽 280，250 ms 防抖。
- 项目筛选。
- 优先级筛选。
- 截止状态：全部、已逾期、今天、未来 7 天、无截止时间。
- “清除筛选”仅在存在非默认筛选时显示。

主体支持 `看板` 和 `列表`，选择保存到本地设置。默认看板。

### 4.2 看板

五列：待规划（backlog）、待处理（todo）、进行中、已阻塞、已完成。已取消默认隐藏，通过筛选显示。

- 列最小宽 260，页面小于 1180 时横向滚动，不压缩卡片文字。
- 列头显示名称和数量；数量来自当前筛选结果。
- 卡片最小高 112：标题最多两行、项目、优先级、截止时间、是否有对话。
- 逾期使用 Warning 文字与图标，不把整卡染红。
- 拖拽时显示目标占位；放下后立即乐观更新，后台失败则动画回原位置并显示错误。
- 同列排序采用卡片之间插值；无可用间隔时仅对该列重新编号。
- 键盘用户可通过卡片菜单“移到……”完成所有拖拽操作。

### 4.3 列表

使用 `ListView`，列为完成框、标题、状态、优先级、项目、截止日期、更新时间。支持按截止日期和更新时间排序；不实现任意表头拖拽。

- Space 打开详情；Enter 打开关联对话（无对话则仍打开详情）；Delete 只打开删除确认，不直接删除。
- 批量选择不属于 V1.3。

### 4.4 任务详情面板

从右侧滑入，宽度 `min(520, 窗口宽度×0.48)`，窗口小于 1100 时覆盖内容并带遮罩。

字段顺序：标题、状态/优先级、空间/项目、截止日期、描述、关联对话、创建/更新时间。截止日期只使用 CalendarDatePicker，不显示时间选择。空间在编辑现有任务时只读；改变空间必须通过“移动任务”操作，V1.3 不实现移动，因此不显示入口。

底部固定操作：

- 次按钮“删除”。
- 次按钮“标记完成”或“重新打开”。
- 主按钮“开始任务/继续任务”。
- 保存按钮仅在有修改时启用；Ctrl+S 保存。

关闭规则：无修改立即关闭；有修改显示“保存并关闭/放弃/继续编辑”。

### 4.5 新建任务

使用同一详情面板。项目默认当前页面最近使用项目；没有项目时为空。提交后新卡片插入对应列首并高亮 1 秒，不弹成功对话框。

## 5. 项目页面调整

- 项目列表只显示当前空间项目。
- 新建项目自动归入当前空间。
- 编辑器顶部显示空间名，只读。
- 项目详情增加“资产索引”区块：状态、文件数、文本资产数、最后完整扫描、数据库占用。
- 操作：开始/继续、暂停、重新构建、编辑忽略规则。
- “重新构建”需确认，会删除该项目旧索引后重建，不删除磁盘文件。
- 项目删除确认增加“将删除本地索引，任务会保留但解除项目关联”。

## 6. 资产页面

### 6.1 页面布局

```text
页头：资产 / 当前空间                         [索引状态]
搜索：关键词输入             [项目] [类型] [时间] [状态]
---------------------------------------------------------
结果列表 62%                         预览详情 38%
```

窗口小于 1100 时预览作为右侧覆盖面板；小于最小宽度不支持。

### 6.2 搜索输入

- 高 44，左搜索图标，右清除按钮；Placeholder“搜索文件名、路径和文本内容”。
- 输入法组合期间不触发搜索；CompositionEnd 后开始 250 ms 防抖。
- Ctrl+K 从任意主页面聚焦资产搜索并导航到资产页。
- 查询运行超过 200 ms 显示细 ProgressBar；旧查询被取消时不闪空状态。
- 查询错误保留旧结果并显示页内 InfoBar。

### 6.3 筛选器

- 项目：当前空间全部项目或单项目。
- 类型：全部、代码、文档、数据、配置、其他；映射由扩展名表决定。
- 时间：任意、24 小时、7 天、30 天。
- 状态：可搜索正文、仅元数据、过大、不支持编码、缺失。
- 筛选器变化立即查询；筛选状态在同一会话内保留，应用重启恢复默认。

### 6.4 搜索结果

每行高 78–112，自适应命中摘要：

- 第一行文件名，命中字符使用 Accent 浅色背景，不改变字重。
- 第二行项目名 · 相对路径，单行省略，Tooltip 显示完整相对路径；不得显示绝对路径。
- 第三行最多两行命中片段；只对正文命中显示。
- 右侧显示文件类型、大小、相对修改时间和状态徽标。
- 多块命中同一资产时默认合并为一条，使用最高分块作为摘要；详情面板列出最多 5 个命中块。
- 分页采用“加载更多”，每次 20，最多加载 50；不做无限滚动。

### 6.5 预览详情

显示文件名、项目、相对路径、大小、修改时间、SHA-256（可复制但默认折叠）、索引状态、命中片段。

- 文本预览最大 100 KiB 或前 2,000 行，先到者为准；超出显示截断提示。
- 预览只读、可选择文本，不执行 HTML，不渲染 Markdown，不加载远程资源。
- 不支持正文的资产显示元数据说明，不显示空白编辑器。
- 操作“复制相对路径”“加入对话”。复制后 Toast 文案“已复制相对路径”。
- “加入对话”打开选择弹层，允许勾选最多 8 个命中块，显示总字符数；没有活动对话时先创建新对话草稿。

### 6.6 索引状态面板

点击页头状态打开 Flyout：按项目显示 `idle/scanning/ready/paused/limit_reached/error`、进度与操作。最多同时显示 20 个项目，更多进入项目页。

进度必须区分：已发现、已处理、正文已索引、跳过、错误。未知总量时使用不确定进度环，不伪造百分比；完成目录发现后才显示确定进度。

## 7. 对话页面调整

- 项目下拉只显示当前空间项目，另提供“显示其他空间项目”开关；跨空间选择后显示空间名。
- 若从任务打开，对话页头显示任务状态胶囊和“查看任务”。
- 输入框“＋”菜单新增“搜索资产”；点击打开轻量资产搜索弹层，行为与资产页一致但只允许选块加入草稿。
- 加入草稿的资产引用以不可编辑引用卡显示，包含项目、相对路径、块序号和删除按钮；正文不直接塞进 TextBox。
- 发送时由 Agent 上下文构建器展开引用卡；用户删除引用后正文不得发送。

## 8. 状态、反馈与动效

- 普通保存成功不弹窗；按钮短暂显示“已保存”不超过 1.5 秒。
- 用户可恢复的错误使用 InfoBar；不可继续的数据库/迁移错误使用 ContentDialog。
- 删除、重建索引、放弃编辑使用确认；普通状态改变不确认。
- 动效 120–180 ms，遵循系统“减少动画”设置。
- 后台扫描不得抢焦点、滚动页面或反复 Toast。

## 9. 键盘与无障碍

| 快捷键 | 行为 |
|---|---|
| `Ctrl+K` | 打开资产页并聚焦搜索 |
| `Ctrl+N` | 当前主页面新建；对话页新建会话，任务页新建任务 |
| `Ctrl+S` | 保存当前编辑面板 |
| `Ctrl+Enter` | 对话发送；多行描述中不提交表单 |
| `Esc` | 关闭 Flyout/面板；有未保存内容时确认 |
| `F6` | 在导航、页头、主体、详情面板间循环 |

- 所有图标按钮必须设置可访问名称和 Tooltip。
- 状态不能只用颜色表达，必须有文字或图标。
- 看板拖拽必须有菜单等价操作。
- 搜索结果命中高亮在高对比主题下使用系统 HighlightBrush。
- Tab 顺序遵循视觉顺序；后台结果更新不得把焦点移走。

## 10. 响应式规则

- ≥1280：完整双栏/看板。
- 1100–1279：缩小间距，详情仍并排；看板允许横向滚动。
- 1024–1099：详情改覆盖面板，侧栏默认折叠。
- 不允许通过缩小正文字号解决拥挤。
