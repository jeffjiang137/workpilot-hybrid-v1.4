# V1.3 产品需求文档

## 1. 背景与问题

V1.2 已能对话并安全访问单个项目目录，但用户缺少三种持续工作能力：项目无法按业务空间分组；对话不能表达正式任务状态；文件只能由模型临时列举，无法快速搜索和复用。V1.3 用本地结构化数据补齐这三项能力，不引入云端和第三方连接器。

## 2. 目标与成功指标

### 2.1 产品目标

- 5 秒内创建空间并切换，页面范围立即更新。
- 30 秒内创建正式任务并从任务进入 Agent 对话。
- 已完成索引的 10,000 文件项目，普通关键词搜索 P95 小于 300 ms。
- 未变更项目的二次扫描跳过率不低于 95%。
- 增量文件变化在正常 Watcher 条件下 3 秒内反映到搜索结果。
- 所有项目文件访问继续通过 C++ 安全核心。

### 2.2 质量指标

- 数据迁移成功率 100%；迁移失败不得丢失 V1.2 表数据。
- 新增领域服务单元测试覆盖率不低于 85%；C++ 路径与扫描核心不低于 95%。
- 无 P0/P1 已知缺陷；无无限缓存、无限撤销、无限扫描和无限重试。

## 3. 用户角色

V1.3 只有一个本机用户角色。不存在管理员、成员、访客和组织角色。Windows 当前用户是密钥与本地数据的安全边界。

## 4. 功能需求

### 4.1 空间

#### 创建

- 必填：名称，去除首尾空白后 1–40 个 Unicode 文本元素。
- 可选：描述，0–500 个文本元素。
- 可选颜色：仅允许设计 Token 中的 8 个预设色 ID，不保存任意色值。
- 创建成功后默认切换到新空间。
- 名称允许重复；UI 通过描述和创建时间区分，不使用名称作主键。

#### 默认空间

- 升级时自动建立“我的空间”，并把所有 V1.2 项目迁入。
- 默认空间可以重命名，但不可删除。
- 当前空间丢失或记录损坏时回退到最早创建的未归档空间。

#### 编辑、归档与删除

- 编辑支持名称、描述、颜色。
- 归档空间后不出现在默认切换列表，但数据保留，可在“已归档”中恢复。
- 包含任何项目或任务的空间不能删除。UI 必须给出数量和处理入口；历史空间应使用归档而不是级联删除。
- 删除为空的非默认空间需要确认，删除不可撤销；不触碰磁盘目录。

#### 切换

- 切换空间改变项目、任务、资产页面默认查询范围。
- 正在运行的 Agent 和索引任务绑定创建时的 `space_id/project_id`，空间切换不得改变其目标。
- 切换不取消用户当前对话；若对话属于其他空间，在页头显示来源空间提示。

### 4.2 正式任务

#### 字段

- 标题：必填，1–120 个文本元素。
- 描述：0–10,000 个文本元素，纯文本，不执行 Markdown HTML。
- 状态：`backlog | todo | in_progress | blocked | done | cancelled`。
- 优先级：`low | normal | high | urgent`，默认 `normal`。
- 空间：必填且不可跨空间关联项目。
- 项目：可空；设置时必须属于任务空间。
- 截止日期：可空，只保存本地日历日期 `YYYY-MM-DD`，不保存时间和时区。`due_date < 今天` 为逾期，等于今天为“今天到期”；改变 Windows 时区不得改变日期。
- 主对话：可空，一个任务最多一个主对话，一个对话最多关联一个任务。
- 排序值：64 位整数；只影响同一状态列内排序。

#### 创建与编辑

- 可从任务页创建；默认状态 `todo`。
- 可从项目页创建并自动绑定当前项目。
- 可从现有对话“转为任务”，保留对话并建立关系，不复制消息。
- 编辑采用显式保存；关闭有未保存内容时弹出“放弃/继续编辑”。
- 同一任务被外部窗口更新时使用 `row_version` 乐观并发；冲突时不覆盖，提示刷新。

#### 状态流转

- `backlog` 可进入 `todo/in_progress/done/cancelled`。
- `todo` 可进入 `backlog/in_progress/done/cancelled`。
- `in_progress` 可进入 `todo/blocked/done/cancelled`。
- `blocked` 可进入 `todo/in_progress/done/cancelled`。
- `done/cancelled` 可重新打开到 `todo`，同时清空 `completed_at`。
- 进入 `done` 设置 `completed_at=now`；离开 `done` 清空。
- 拖拽只是状态和排序操作，失败必须回滚 UI。

#### 从任务执行 Agent

- “开始任务”在没有主对话时创建对话，有则打开原对话。
- 首次启动向输入框预填任务上下文，不自动发送：标题、描述、项目说明和验收目标。
- 点击发送后，Agent 上下文包含只读任务元数据；资产内容仍必须通过搜索或读取工具获取。
- Agent 完成一轮不会自动把任务设为完成，必须由用户点击或明确向 Agent 发出更新任务状态的指令；V1.3 不向模型暴露任务写工具，因此实际状态仍由 UI 更新。

### 4.3 资产索引

#### 索引范围

- 仅索引绑定工作区且目录可访问的项目。
- 默认忽略：`.git`、`.svn`、`.hg`、`.vs`、`node_modules`、`bin`、`obj`、`artifacts`、`dist`、`build`、`packages`、`.cache`。
- 支持项目级忽略规则，每行一个相对 glob；只支持 `*`、`?`、`**` 和前导 `!` 反选，禁止执行正则。
- 默认不索引隐藏和系统文件；用户可在项目索引设置中打开“包含隐藏文件”，系统文件始终排除。
- reparse point、符号链接、目录联接、设备文件、网络共享全部排除。

#### 文件类型

- 正文白名单：`.txt .md .markdown .json .jsonc .xml .yaml .yml .csv .tsv .html .htm .css .scss .less .js .jsx .ts .tsx .cs .cpp .cc .c .h .hpp .java .kt .py .go .rs .php .rb .swift .sql .ps1 .bat .cmd .ini .toml .env .gitignore`。
- 白名单外文件只建立名称、路径、大小、修改时间和类型元数据。
- UTF-8 BOM 可接受并移除；有效 UTF-8 无 BOM 可接受；其他编码在 V1.3 标记 `unsupported_encoding`，不猜测编码。
- 正文大小上限 512 KiB；超限状态 `metadata_only_size_limit`。

#### 索引操作

- 新建或修改工作区后自动安排首次扫描，但不阻塞项目保存。
- 用户可暂停、继续、取消、重新构建索引。
- 取消保留已提交批次，状态变为 `paused`；重新构建使用新 generation，旧任务不得覆盖新结果。
- 项目删除只删除索引与配置，不删除磁盘文件。
- 应用启动后对最近使用项目做一次轻量校验；完整重扫由变更、Watcher 溢出、用户操作或距离上次完整扫描超过 12 小时触发。

### 4.4 资产搜索

- 默认搜索当前空间全部项目，可筛选单项目、文件类型、索引状态和修改时间。
- 空查询显示最近修改资产，不执行 FTS。
- 搜索范围：文件名、相对路径、文本块正文。
- 输入停止 250 ms 后查询；新查询取消旧查询，旧结果禁止覆盖新结果。
- 每个结果显示：文件名、相对路径、项目、类型、修改时间、命中片段和索引状态。
- 点击结果打开右侧预览；双击或 Enter 打开系统默认程序前必须二次确认“将交由系统应用打开”，V1.3 默认不实现直接外部打开也可，但不得保留无效按钮。
- “加入对话”只把用户选中的最多 8 个文本块加入当前对话草稿；显示预计字符数和来源，用户确认后才发送。
- 搜索结果内容一律标记为不可信引用，不得被解释为系统或权限指令。

## 5. 空状态与错误行为

| 场景 | 必须显示 |
|---|---|
| 没有空间 | 自动恢复默认空间；若失败，显示数据库修复错误，不显示空白页。 |
| 空间无项目 | 创建项目按钮和用途说明。 |
| 没有任务 | 创建任务按钮，不生成示例任务。 |
| 项目未绑定目录 | “未绑定工作区，无法索引”，提供编辑项目入口。 |
| 正在扫描 | 已扫描数量、已索引数量、跳过数量、当前相对路径、取消按钮。 |
| 索引暂停 | 原因、继续和重新构建入口。 |
| 无搜索结果 | 当前关键词与筛选摘要、清除筛选入口。 |
| 路径失效 | 资产标记 `missing`，不立即删除；完整重扫确认后删除索引。 |
| 数据库繁忙 | 最多按 100/250/500 ms 重试三次，仍失败则明确提示，不无限重试。 |

## 6. 隐私与安全

- 搜索与索引完全本地执行。
- 资产正文不得进入日志、遥测、崩溃信息、任务标题和系统剪贴板。
- 只有用户主动选择“加入对话”或 Agent 经权限链调用搜索工具时，相关片段才可发给模型。
- 搜索工具最多返回 8 块、每块最多 4,000 字符、总计最多 20,000 字符。
- 索引结果中发现“忽略规则、泄露密钥、执行命令、覆盖系统指令”等内容时仅作为文本返回，并附 `untrusted_asset_content=true`。

## 7. 发布条件

- 数据库版本提升至 V1.3，迁移可重复检测但不可重复执行。
- V1.2 安装目录升级、用户数据保留、卸载行为不变。
- Release 包不包含测试资产、真实用户路径、API Key、数据库和日志。
- README 更新已实现范围与明确非目标。
- 安装器版本更新为 `1.3.0`，产物名更新但 AppId 保持不变以支持覆盖升级。
