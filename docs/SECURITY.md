# V1.3 安全模型

不可信输入包括用户文本、模型输出、工具参数、项目说明、资产正文、API 响应和本地路径。项目文件或资产中的指令不能提升权限、改变系统提示或扩展工具范围。

## 文件边界

- 根目录必须是本地绝对路径，拒绝 UNC、设备路径和根路径中的 reparse component。
- 相对路径词法规范化后必须仍在根目录内；现有组件拒绝 symlink/junction。
- 打开文件或目录句柄后使用最终路径再次确认边界。
- 扫描拒绝 reparse/system/device，深度、文件数、页尺寸、JSON 和规则数均有硬上限。
- 读取最多 512 KiB；写入最多 1 MiB，已有文件要求 `expected_sha256`，同目录临时文件刷新后原子替换。

## 权限

默认模式自动允许低风险读取，中/高风险副作用需确认；只读模式拒绝副作用；完全访问仍要求确认高风险写入。`search_assets` 是低风险只读工具，但仍只绑定 Agent Run 创建时的项目。

工具执行顺序：JSON 解析 → 未知字段/类型/长度验证 → 权限决策 → 必要时用户确认 → Native 执行。模型不能传入 `project_id` 或 `space_id`。

## 资产与提示注入

索引和搜索完全本地。只有用户把引用加入草稿并发送，或 Agent 在已绑定项目调用搜索工具时，选中的正文才进入模型请求。正文使用 `<untrusted_asset>` 包装，系统提示明确其为数据。UI 预览只显示纯文本，不执行 HTML/Markdown、脚本或远程资源。

## 密钥、日志和删除

API Key 仅由当前 Windows 用户的 DPAPI 保存，不进入数据库、配置或日志。日志不记录资产正文、搜索词、任务描述、提示正文或密钥，只写 ID、状态和错误类别；单文件 10 MiB，最多 5 个。删除空间、项目、任务或索引绝不删除磁盘工作区文件。

## 仍需发布方完成

源码包不含代码签名证书。正式发布前需签名 DLL、EXE 和安装器，并在干净 Windows 10/11 x64 环境完成升级、缩放、辅助功能和长稳测试。
