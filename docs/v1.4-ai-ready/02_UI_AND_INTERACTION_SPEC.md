# UI 与交互规范

## 1. 导航与布局

左侧导航在 V1.3 的“新建任务、任务、项目、资产”之后增加：

1. 专家
2. 技能
3. 连接
4. 安全中心

“连接”页内部使用“连接器 / MCP 服务”页签，不再增加第二层侧栏。窗口宽度小于 1,080 px 时，详情面板覆盖内容区并提供明确返回按钮；小于 760 px 不承诺完整双栏布局，但所有操作仍可滚动到达。

通用尺寸：

- 页面边距 24 px；紧凑窗口 16 px。
- 列表行最小高度 48 px；主要按钮最小高度 36 px。
- 左侧列表建议宽度 320 px，允许 280–420 px 拖动。
- 所有状态不得只靠颜色表达；图标旁必须有文字。
- 危险操作按钮不使用默认焦点；确认框默认焦点为“取消”。

## 2. 专家页面

### 2.1 专家列表

顶部包含：标题、搜索框、“新建专家”主按钮。列表项显示头像色块、名称、简短描述、启用技能数、连接数、状态和最后修改时间。

列表状态：

| 状态 | 展示 | 操作 |
|---|---|---|
| 加载 | 6 行骨架屏 | 可取消页面导航 |
| 空 | 插图占位 +“创建第一个专家” | 主按钮可用 |
| 搜索无结果 | 搜索词和“清除筛选” | 不展示创建误导 |
| 错误 | 短原因、错误码、重试 | 保留搜索词 |
| 已归档 | 默认隐藏，可筛选 | 恢复、永久删除（无引用时） |

右键菜单与 `...` 菜单必须一致：编辑、复制、导出摘要、归档。内置“默认助手”没有归档和删除，仅有查看与恢复默认。

### 2.2 新建/编辑专家

使用五步向导，左侧步骤导航可回到已完成步骤：

1. 基本信息：名称、描述、颜色、模型偏好。
2. 行为：系统指令编辑器，字符计数，危险提示词不自动改写。
3. 技能：已安装技能搜索、勾选、排序；最多 20 个。
4. 连接：按空间筛选可用连接器/MCP；默认不勾选。
5. 权限与检查：风险策略、摘要、验证错误和保存。

保存规则：

- 字段失焦进行轻量校验，点击保存进行完整校验。
- 首个错误获得焦点；步骤标题显示错误数量。
- 未保存关闭时弹出“放弃更改 / 继续编辑”。
- 保存期间禁用重复提交；取消保存只在数据库事务开始前有效。
- 并发修改使用 `row_version`。冲突时提供“重新加载”和“另存为副本”，不得静默覆盖。

### 2.3 专家详情

页签：概览、技能、连接、权限、修订。

- 概览显示行为摘要、当前修订、模型、引用空间和最近运行。
- 修订页显示版本号、时间、字段级变化摘要。不得展示完整秘密或完整系统提示；系统提示仅显示字符数和 SHA-256 前 12 位。
- “试运行”打开右侧面板，允许输入一条测试消息；只执行内置只读能力，外部能力以“将请求……”模拟卡片展示。

## 3. 技能页面

### 3.1 已安装列表

顶部：搜索、状态筛选、来源筛选、“导入技能”。卡片显示名称、发布者、版本、状态、绑定专家数、内容哈希短值。

技能状态：已启用、已停用、有更新版本、本地文件缺失、验证失败。验证失败的技能永远不进入提示编译。

### 3.2 导入流程

步骤必须顺序执行：

1. 选择或拖入一个 `.zip`。
2. 显示“正在安全检查”，支持取消。
3. 展示清单、包哈希、文件数、解压大小、权限声明和验证结果。
4. 用户确认安装。
5. 原子安装后展示可绑定专家。

校验失败页必须显示：规则编号、文件相对路径、JSON Pointer/行号（可得时）、问题描述和修复建议。不得提供“忽略并安装”。

同 ID 同版本同哈希：提示已安装，不重复写入。  
同 ID 同版本不同哈希：判定为冲突，拒绝覆盖。  
更高版本：显示升级影响；安装后保留旧版本，已运行快照不切换。  
更低版本：只有“安装为可回滚版本”，不自动设为当前版本。

### 3.3 技能详情

页签：说明、文件、使用专家、版本。文件页仅预览 `.md/.txt/.json`，单文件预览 256 KiB；二进制静态资源仅显示名称、大小、哈希。

“为什么被激活”浮层显示：技能 ID、版本、专家固定状态、匹配词、得分、选择阈值和是否因预算未选中。

## 4. 连接页面

### 4.1 连接器页签

上部为连接状态筛选；卡片显示 GitHub/Notion 图标、用户自定义连接名、脱敏身份、状态、启用空间数、最后检查。

添加连接：

1. 选择类型。
2. 显示最小所需权限、隐私说明和外部创建 token 指引。
3. 输入 token；输入框禁止复制到遥测，默认隐藏，可按住显示。
4. 测试连接，展示识别到的账号和授权范围。
5. 选择启用空间；默认全不选。
6. 保存。

测试失败必须区分：无效凭据、权限不足、限流、离线、证书/TLS、服务端错误。原始响应正文只进入内存诊断摘要并立即丢弃。

连接详情页签：概览、空间、专家、能力、诊断。删除连接前展示受影响专家和空间；输入连接名称确认。删除成功后撤销授权和秘密。

### 4.2 MCP 服务页签

列表项显示服务名、传输方式、位置摘要、状态、协议版本、能力数量、风险概况。

添加向导：

1. 类型：本地 stdio / 远程 Streamable HTTP。
2. 配置：
   - stdio：绝对 EXE 路径、参数数组编辑器、工作目录、环境变量引用。
   - HTTP：Endpoint URL、认证方式、本地模式开关。
3. 安全预览：程序签名/发布者（可得时）、主机、解析地址、所需秘密、可见风险。
4. 测试初始化：只做 initialize 和能力列举，不调用工具。
5. 能力审查：按 tools/resources/prompts 分组，默认全部未授权。
6. 选择空间并保存。

参数编辑器每行一个参数，按原样作为数组元素传递；不提供 shell 命令文本框。环境变量值只能为普通非秘密值或 SecretService 引用，秘密编辑后只显示“已设置”。

### 4.3 MCP 详情

页签：概览、工具、资源、提示、日志、权限。

- 工具表显示本地稳定名、服务端原名、描述、Schema 摘要、本地风险、服务端 annotations、是否授权。
- Schema 变化时显示“能力已变化”，旧授权暂停；用户查看 diff 后重新批准。
- 资源页只有用户点击时读取；不得打开页面就批量读取内容。
- 提示页点击“预览”调用 `prompts/get`，结果以“不可信外部提示”横幅展示；点击“插入当前对话”才生效。
- 日志仅展示脱敏生命周期、stderr 摘要和错误码，默认保留本次会话 1 MiB 环形缓冲。

## 5. 对话与任务集成

### 5.1 专家选择器

新对话输入区上方显示专家选择器。切换规则：

- 对话尚无用户消息：立即切换。
- 已有消息：提示“新建对话并切换”或“取消”；不得在原会话换修订。
- 专家已归档：旧会话仍可查看，继续对话前必须选择当前专家创建分支。

标题区显示：专家名、修订号、已启用技能数、外部连接状态。点击展开“本次运行能力快照”。

### 5.2 能力调用卡片

状态顺序：准备 → 等待授权（可选）→ 执行中 → 成功/失败/已取消。

卡片展示：

- 稳定能力名和来源。
- 风险级别。
- 输入摘要；秘密字段显示 `••••`。
- 执行耗时和返回条数/字符数，不默认展开完整正文。
- 失败类别、可重试性和下一步。

### 5.3 高风险确认框

必须包含：

- 动词式标题，例如“允许在 GitHub 创建 Issue？”
- 来源与连接账号。
- 目标仓库/页面/资源。
- 将发送的数据摘要和不可逆影响。
- 授权范围单选：仅此一次；本次会话（只在策略允许时）。
- “取消”和“允许”按钮；默认焦点取消。

以下情况不显示“本次会话”：删除、执行本地程序、资金、凭据传输、未知 Schema、连接器写操作。V1.4 所有 GitHub/Notion 写操作均仅此一次。

## 6. 安全中心

页签：概览、授权、审计、诊断。

- 概览：运行中 MCP 数、过期凭据、暂停授权、高风险调用数、最近错误。
- 授权：按空间 → 专家 → 来源 → 能力的层级查看，可撤销会话授权或禁用来源。
- 审计：筛选时间、空间、专家、来源、风险、结果；导出脱敏 JSONL。
- 诊断：协议版本、健康状态、队列深度、熔断状态；不得显示秘密或完整载荷。

撤销立即影响下一次调用；已经发出的网络请求无法保证撤回，UI 必须明确说明。禁用 MCP 时取消未发送请求，并对进行中的请求发送取消通知（若支持）后在超时处置。

## 7. 键盘、焦点与可访问性

- `Ctrl+N` 在当前模块新建；专家/连接向导中不触发全局新对话。
- `Ctrl+F` 聚焦当前列表搜索。
- `Esc` 关闭最上层非阻塞浮层；有未保存内容时先确认。
- `Alt+Left` 返回详情列表，不丢失已提交状态。
- 所有图标按钮具有 AutomationProperties.Name。
- 状态变化通过 LiveRegion 宣告，但执行进度最多每 2 秒宣告一次。
- 错误文本与字段通过 `DescribedBy` 关联；焦点顺序遵循视觉顺序。

## 8. 文案与错误格式

用户错误格式：`发生了什么 + 数据是否安全 + 可以怎么做 + 错误码`。

示例：

> 无法连接到 MCP 服务。配置已保存，没有工具被调用。请检查服务地址或打开诊断。错误码：MCP-TRANSPORT-004。

不得向用户直接展示异常堆栈、OAuth token、完整本地路径中的用户名或外部响应正文。
